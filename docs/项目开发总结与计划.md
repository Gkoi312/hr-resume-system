项目开发总结与计划.md# 项目开发总结与计划

## 已完成工作

### 后端核心（前期完成）
- FastAPI 后端服务，含 6 组 API 端点（auth / jobs / resumes / candidates / matching / tasks）
- 8 张数据表：users, jobs, candidates, resumes, candidate_job_matches, tasks, vector_profiles, rag_evaluations
- 简历解析管线：文本 LLM / 视觉 LLM / PaddleOCR+规则，按文件类型自动路由
- JD 文件解析：PDF/DOCX/TXT → 结构化 JSON
- **匹配管线**：学历硬过滤 → 多轴语义打分（技能 20% / Delivery 80% / 角色 0%）→ 技能规则分 → LLM 质量分 → 加权综合分
- **混合检索**：自研 BM25（jieba 中文分词）+ 向量余弦 + RRF 融合
- 数据库级异步任务队列（SKIP LOCKED）+ Worker
- JWT 认证 + 岗位数据权限
- 12 个测试文件，40 条测试用例

### 本轮新增（2026-06-27）

#### 1. Demo 前端页面 (`demo/`)
- Streamlit 构建，4 页：首页 / 岗位管理 / 简历批量上传 & 候选人库 / 匹配分析

#### 2. Docker 化
- `Dockerfile`：Python 3.10 + 系统依赖 + pip 安装 + streamlit

### Benchmark 结果（`MATCH_LLM_ENABLED=0`）

**排序质量（15 jobs × 40 candidates）**

| K | Precision | Recall | NDCG |
|---|-----------|--------|------|
| @1 | **1.0000** | 0.2814 | **1.0000** |
| @3 | 0.9111 | 0.6441 | 0.9740 |
| @5 | 0.7867 | 0.8213 | 0.9869 |
| @10 | 0.5200 | 0.9852 | 0.9852 |

- **MRR = 1.0000**：所有 15 个岗位，最高相关候选人均排第一位
- 未开 LLM 质量评分时，Skill × Quality 乘法公式已能达到上述精度

**延迟（40 候选人 / 单岗位，avg）**

| 阶段 | 耗时 | 占比 |
|------|------|------|
| 教育过滤 | 5ms | 4% |
| 语义打分 | 62ms | 50% |
| 技能打分 | <1ms | 0% |
| DB 读写等 | 57ms | 46% |
| **总计** | **125ms** | |

**并发**：3 岗位串行 391ms / 并行 406ms，加速比 1.0x（瓶颈在 DB 连接池）
