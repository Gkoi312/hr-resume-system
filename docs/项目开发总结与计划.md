# 项目开发总结与计划

## 已完成工作

### 后端核心（前期完成）
- FastAPI 后端服务，含 6 组 API 端点（auth / jobs / resumes / candidates / matching / tasks）
- 8 张数据表：users, jobs, candidates, resumes, candidate_job_matches, tasks, vector_profiles, rag_evaluations
- 简历解析管线：文本 LLM / 视觉 LLM / PaddleOCR+规则，按文件类型自动路由
- JD 文件解析：PDF/DOCX/TXT → 结构化 JSON
- **匹配管线**：学历硬过滤 → 多轴语义打分（技能 20% / Delivery 80% / 角色 0%）→ 技能规则分 → LLM 质量分 → 加权综合分
- **混合检索**：自研 BM25（jieba 中文分词）+ 向量余弦 + RRF 融合
- 数据库级异步任务队列（SKIP LOCKED）+ Worker
- JWT 认证 + 岗位数据权限
- 12 个测试文件，40 条测试用例

### 本轮新增（2026-06-27）

#### 1. Demo 前端页面 (`demo/`)
- Streamlit 构建，4 页：首页 / 岗位管理 / 简历批量上传 & 候选人库 / 匹配分析
- 侧边栏一键登录，跨页共享 JWT token
- 匹配结果可展开查看完整 MatchExplanation（技能对比、语义证据、Delivery Alignments 表、LLM 质量评估、分数拆解）
- 简历支持批量上传（一次选多个文件，带进度条）

#### 2. Docker 化
- `Dockerfile`：Python 3.10 + 系统依赖 + pip 安装 + streamlit
- `docker-compose.yml`：5 服务编排
  - `db`：pgvector/pgvector:pg16
  - `api`：FastAPI 后端
  - `worker`：异步任务消费
  - `seed`：一次性灌入 3 JD + 10 候选人
  - `demo`：Streamlit 前端
- `.env.docker`：Docker 环境专用变量（debug embedding，零外部依赖）
- 一条 `docker-compose up` 全部启动

#### 3. Seed 数据 (`scripts/seed_demo_data.py`)
- 3 个岗位：后端开发实习生 / 前端开发实习生 / 数据分析实习生
- 10 个候选人：清华大学硕士到专科生，技能和学历阶梯分布
- 学历不满足的候选人可展示硬过滤功能

#### 4. CI/CD (`.github/workflows/test.yml`)
- GitHub Actions：push/PR → pytest，内存 SQLite 无需 PostgreSQL
- 40 条测试全部通过

#### 5. README 更新
- CI 徽章
- Docker 一键启动说明
- Demo 前端说明

#### 6. 面试文档 (`docs/面试要点与项目亮点.md`)
- 5 个高频面试问答题（混合检索 / 三层打分 / 异步队列 / Candidate 数据模型 / 学历过滤前置）
- 技术亮点总结
- 可改进方向
